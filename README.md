# DigitalControl

Информационный frontend-портал промышленной безопасности.
Каталог показывает 32 сценария видеоаналитики при бурении и текущем / капитальном
ремонте скважин: иллюстрацию опасной ситуации, текст голосового предупреждения
и причину срабатывания.

**[Открыть сайт](https://saven0k.github.io/Digitalcontrol/)**

## Возможности

- 18 сценариев бурения и 14 сценариев ТКРС с фильтрацией по направлению работ.
- Карточки с подробным описанием: одновременно открыт один сценарий.
- Прокрутка к выбранной карточке с учётом закреплённой навигации.
- Адаптивный интерфейс, управление кнопками через Enter и Space, видимый фокус.
- ARIA-связи карточек и панелей, объявление изменения фильтра, ссылка для пропуска навигации.
- Уважение настройки уменьшения движения и загрузка иллюстраций только при раскрытии карточки.

Это статический информационный сайт. Он описывает работу системы видеоаналитики;
само приложение не анализирует видеопотоки и не подключается к камерам.
Все данные находятся в репозитории; backend, API, аккаунты и переменные окружения не нужны.

## Стек

React 19, TypeScript 6, Vite 8, React Compiler, CSS, ESLint.
Состояние интерфейса — React Hooks; маршрутизация и внешнее хранилище не требуются.

## Локальный запуск

Нужны Node.js 22.12+ и npm.

```sh
git clone https://github.com/Saven0k/Digitalcontrol.git
cd Digitalcontrol
npm ci
npm run dev
```

Адрес разработки: `http://localhost:5173/Digitalcontrol/`.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Vite с обновлением интерфейса при изменении исходников |
| `npm run lint` | Проверка TypeScript / React-кода через ESLint |
| `npm test` | Проверка каталога: уникальные ID, категории, описания и иллюстрации |
| `npm run build` | Строгая проверка TypeScript и production-сборка в `dist/` |
| `npm run check` | Линтинг, тесты и production-сборка |
| `npm run preview` | Локальный просмотр production-сборки |
| `npm run deploy` | Сборка и публикация `dist/` в ветку `gh-pages` |

## Структура

```text
src/
  components/       Разделы страницы и управляемая карточка сценария
  data/data.ts      Типизированный каталог и локальные иллюстрации
  types/scenario.ts Общая модель сценария и категории
  assets/           Изображения и шрифт исходного проекта
  App.tsx           Композиция страницы и семантические landmarks
  index.css         Токены оформления, общие стили, доступность
tests/
  catalog.test.mjs  Целостность каталога и наличие иллюстраций
public/
  favicon.svg      Значок сайта
```

Компоненты используют собственные CSS-файлы с именованием классов по BEM.
Цвета, ширина страницы, отступы и высота навигации заданы CSS-переменными
в `src/index.css`. TypeScript работает в строгом режиме.

Для добавления сценария внесите запись в соответствующий массив
`src/data/data.ts` и добавьте иллюстрацию в `src/assets/images/`.
Поля определены в `src/types/scenario.ts`. ID должны быть уникальны
во всём каталоге, включая обе категории. Счётчики фильтров вычисляются из данных.
При изменении состава каталога обновите ожидаемые количества в тесте и описание проекта.

## Публикация

Исходники находятся в ветке `master`, готовый сайт — в `gh-pages`.
Перед релизом выполните `npm run check` и проверьте интерфейс на мобильном и
десктопном экранах.

```sh
git push origin master
npm run deploy
```

GitHub Pages должен использовать **Deploy from a branch → gh-pages → / (root)**.
В `vite.config.ts` задан `base: '/Digitalcontrol/'`; при переносе в другой
репозиторий обновите этот путь и `homepage` в `package.json`.
