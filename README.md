## 📋 О проекте

Система видеоаналитики — это интеллектуальное решение для повышения безопасности на производственных объектах. Приложение анализирует видеопоток с камер в режиме 24/7 и мгновенно оповещает о потенциально опасных ситуациях.

### 🎯 Основные возможности

- **📹 Интеллектуальный мониторинг** — система в реальном времени анализирует видеопоток
- **🔔 Мгновенные оповещения** — голосовые предупреждения при обнаружении нарушений
- **📊 Категоризация сценариев** — фильтрация по типам работ (Бурение, ТКРС, Транспорт)
- **📱 Адаптивный дизайн** — корректное отображение на всех устройствах
- **🎨 Интуитивный интерфейс** — удобная навигация и визуализация данных

## 🚀 Установка и запуск

### Требования

- **Node.js** >= 18.x
- **npm** >= 9.x
- **Git** (опционально)

### Клонирование репозитория

```bash
git clone https://github.com/Saven0k/Digitalcontrol.git
cd Digitalcontrol

```

### Установка зависимостей
npm install

### Запуск в режиме разработки
npm run dev

#### Приложение будет доступно по адресу: http://localhost:5173


### Сборка для продакшена
npm run build

### Деплой на GitHub Pages
npm run deploy
